Plan of Plans

The tracking board for building the QIF heterogeneous chiplet system on Rapid-LLM: analog FWS-CIM macro chiplets plus shared digital chiplets, running ≤7B-total-parameter edge inference. Six superplans, one decisions register, and the audit trail. Plans are documents George reads; nothing here enforces anything (D18).

The architecture stance

A1 — DAG-first. No period law anywhere. The op DAG is built on the program IR, priced per op, evaluated fully analytically. AstraSim OFF; fully-connected p2p; no congestion.
A2 — heterogeneous device layer. Ops sit on typed devices: analog macro, per-macro digital pool, shared digital chiplet, link.
A3 — the macro is the atomic resource; the tile is the allocation unit. One macro can host tiles of many layers, experts, or models. Mapping is the assignment.

Full register: DECISIONS.md (D1–D23 + ADJ-1–8, raw markdown).

P3 · Mapping

The centerpiece: tiles→macros→chips→system, tp/ep/pp as first-class groups, heterogeneous op placement, PD disaggregation, honest boundary checks — output is a placed op DAG.

P4 · Evaluation

One simulated timeline; every published metric is a projection of it. Heterogeneous device pricing in the analytical evaluator, memory verdicts, itemized energy, the two reports.

P5 · The System Atlas

The interactive mapping picture: package→chip→macro→tile, colored by tp/ep/pp, one self-contained HTML file. Also the mapper's honesty enforcer — it only draws real placements.
